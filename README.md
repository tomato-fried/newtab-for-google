# New Tab for Google - Search Focus

Chrome / Edge extension. Replaces the new tab page with Google.
The cursor goes to the Google search box, not the address bar.

Chrome Web Store: ストアのURL

- Manifest V3
- No permissions
- No JavaScript
- Collects no data

newtab.html just redirects to Google with meta refresh. That's all.

Not affiliated with Google.

## Install

Chrome: Install from the Chrome Web Store link above.

Edge: Open the Chrome Web Store link above in Edge, click "Allow extensions from other stores", then "Add to Chrome".

Manual (Chrome / Edge): chrome://extensions or edge://extensions -> Developer mode -> Load unpacked -> select the extension folder
